# rollipv6

Roll validation gates for ipv6 inputs before they hit prod.

**Site:** https://theworker02.github.io/rollipv6/

## Install / run

```bash
git clone https://github.com/theworker02/rollipv6.git
cd rollipv6
node src/cli.js
node --test
```
